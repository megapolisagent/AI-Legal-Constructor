# Открытые вопросы

Не решать самостоятельно — фиксировать здесь и спрашивать в моменте, когда вопрос
реально встал в диалоге.

- Точный список оснований для `consent_flags` (когда именно согласие обязательно по
  закону) — решает юрист. См. `knowledge/deal-schema.md`.
- Технический носитель агента (Claude Code напрямую / отдельное приложение) — не решается
  этим репозиторием.
- Если инструмент выйдет за рамки личного использования Марии (другие сотрудники, другие
  агентства) — правило «фото можно присылать в диалог» (`DECISIONS.md`, 2026-08-21) нужно
  пересмотреть отдельно, не считать автоматически перенесённым на новый масштаб.
