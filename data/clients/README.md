# Клиентские дела

Реальные документы по делам — договоры, оригиналы, переписка. Не для широкого поиска по
умолчанию (см. `HOME.md`) и не в git (`.gitignore`).

Структура: `data/clients/<слаг-дела>/<подпапка по типу материала>/`.

Перенесено из корня репозитория 2026-09-03 (независимый аудит Codex + план
`ENGINEER/advisory_enhancement_plan.md`, Блок 1.2) — раньше клиентские файлы лежали прямо в
корне и попадали в область видимости при любой широкой задаче типа «проверь все docx».
