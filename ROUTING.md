# Роутинг

Не читай всё сразу — под конкретную потребность конкретный файл.

| Потребность | Что читать |
|---|---|
| Собираю данные сделки / проверяю полноту / генерирую документы | `skills/document-assembly/SKILL.md` |
| Нужна схема Deal/Participant или правила состава комплекта | `knowledge/deal-schema.md` |
| Отвечаю на вопрос по практике (доли, согласия, нестандартные ситуации) — было ли похожее раньше | `knowledge/precedents.md` |
| Проверяю, не решён ли уже этот архитектурный/правиловый вопрос | `DECISIONS.md` |
| Вопрос без ответа в своих файлах, нужно узнать про мир/закон | `OPEN_QUESTIONS.md` — зафиксировать, не изобретать ответ |
| Кто владелец, как с ней работать | `PROFILE.md` |

## Меню vs прямой запрос

Задача уже названа словами (даже неточно, «нужен договор аренды») — работай напрямую, не
показывай меню. «Продолжи» — открой последнюю сделку в `deals/` по дате изменения.
