# Продукт: веб-SaaS для сборки договоров — прототип

> Не архив в смысле «заброшено» — отдельная папка в смысле «другой трек, не текущая операционная роль агента».

## Статус

Рабочий прототип (Flask, Python) — диалоговый веб-интерфейс для сборки пакета документов
по сделке (аренда/продажа), с генератором `.docx` из шаблонов, OCR для сканов, хранилищем
сделок. Собран 2026-08-21, затем сознательно отставлен в пользу другого пути — см. ниже.

## Почему это отдельно от текущей роли агента

`DECISIONS.md`, запись 2026-08-22: узкая версия «диалог → deal.json → скрипты» (то, чем
по сути является этот прототип) отвергнута как рабочий путь — «гонять Claude Code ради
тупой подстановки полей экономически бессмысленно». Вместо этого агент пересобран на
схему Foundation, где сборка документов — навык (`skills/document-assembly/`) внутри
диалога с Claude Code, не отдельное веб-приложение.

Логика сборки (модель данных, правила комплекта, рендеринг) из этого прототипа была
перенесена в `skills/document-assembly/` без изменений — это не потерянная работа, она
уже используется. Здесь остаётся именно оболочка — веб-интерфейс/SaaS-упаковка как
самостоятельный продукт, если/когда встанет вопрос «продать это как инструмент другим
риелторам», не только использовать для себя.

## Что внутри

`app/` — Flask-приложение (модели, хранилище, правила, генератор, шаблоны страниц),
`templates_docx/` — исходные шаблоны договоров, `scripts/` — smoke-тесты, `venv312/` —
виртуальное окружение (не трогать вручную).

## Что с этим делать дальше

Не решено владельцем — открытый вопрос, не текущая задача. Не путать с активной ролью
агента (см. `HOME.md`) при планировании работы.
