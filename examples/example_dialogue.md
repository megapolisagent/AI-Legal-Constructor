# Пример диалога — от старта сделки до готового комплекта

Показывает стиль ведения интервью (по одному блоку, не всё сразу) — не сценарий для
копирования дословно, реальные вопросы зависят от того, что человек говорит.

---

**Мария:** Новая сделка, сдаём квартиру.

**Агент:** Аренда — понятно. Адрес объекта и кадастровый номер?

**Мария:** Москва, ул. Примерная, д. 1, кв. 2. Кадастровый 77:01:0001001:1234.

**Агент:** Площадь, количество комнат, основание права собственности есть под рукой?

**Мария:** 65.4 кв.м, 2 комнаты, свидетельство о праве собственности. Обременений нет.

**Агент:** Записала. Теперь участники со стороны объекта — кто собственник (или
собственники)?

**Мария:** Два — Иванова Ирина Ивановна и Иванов Пётр Иванович, пополам.

**Агент:** По каждому нужны паспортные данные и адрес регистрации — начнём с Ивановой?

*(агент собирает данные по каждому участнику отдельно, для Ивановой дополнительно
уточняет: «Ирина Ивановна в браке?» — раз да, ставит флаг `is_married`)*

**Агент:** Оба записаны, доля 1/2 у каждого. Со стороны арендатора кто?

**Мария:** Петров Иван Петрович, один.

*(собирает данные Петрова)*

**Агент:** Участники все. Теперь условия: цена, порядок расчётов, срок, комиссия по
каждому участнику?

**Мария:** 120 000 в месяц, до 5 числа, на 11 месяцев с пролонгацией. Задаток тоже
120 000. Комиссия — 50% от ставки с каждого собственника, 100% с арендатора.

**Агент:** Есть особые условия — животные, субаренда, что-то ещё?

**Мария:** С кошкой можно.

**Агент:** Записываю пункт: «Проживание с одной кошкой допускается» — верно?

**Мария:** Да.

**Агент:** *(запускает `check_completeness.py`)* Комплект — 6 документов: 3 комиссии
(Иванова, Иванов, Петров), основной договор, акт приёма-передачи, согласие супруга
(Иванова Ирина Ивановна). Данных достаточно, ничего не не хватает. Собирать?

**Мария:** Да.

**Агент:** *(запускает `generate_package.py`)* Готово, 6 файлов в `output/deal_.../`:
комиссии на всех троих, основной договор, акт, согласие супруга. Это черновики — перед
подписанием их должен посмотреть юрист.
