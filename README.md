# AI Legal Constructor

Инструмент для агентства «Мегаполис» (Мария Боголюбова): собирает комплект договоров
(аренда/продажа) из данных сделки — веб-форма → генератор → набор `.docx`. Локальное
приложение, данные не покидают компьютер.

**Source of truth требований — не этот README:**
`MAIN_ASSISTANT\knowledge\projects\legal-contract-constructor-handoff.md` (v1.1).
Решение о выборе архитектуры и Human Override по Roadmap — `MAIN_ASSISTANT\DECISIONS.md`,
запись 2026-08-21. Дословная задача и ход сборки —
`ENGINEER\workspace\2026-08-21-задача-юридический-конструктор-договоров.md`.

## Статус

**Phase 1 (MVP), только что собран.** Реализовано: динамическая модель Deal/Participants,
логика комплекта (комиссия на каждого / основной договор / акт / согласия по флагам),
реестр шаблонов с одной активной версией на тип, 4 экрана веб-формы, экспорт `.docx`
(по одному и архивом).

**Шаблоны в `templates_docx/` — тестовые заглушки, не юридический текст.** Реальные
шаблоны (6 штук — 3 аренда + 3 продажа) готовят Мария с юристом отдельно; движок проверен
на плейсхолдерах и примет реальные `.docx`-шаблоны с той же Jinja-разметкой
(`{{ address }}`, `{{ participant.full_name }}`, циклы `{% for p in participants %}`)
без изменений кода — см. «Как заменить шаблоны на реальные» ниже.

## Запуск

```bash
pip install -r requirements.txt
python scripts/make_placeholder_templates.py   # один раз — создать тестовые .docx-шаблоны
python run.py
```

Открыть в браузере: http://127.0.0.1:5001

## Проверка (сделано при сборке, можно повторить)

```bash
python scripts/smoke_test.py        # движок напрямую, без HTTP
python scripts/http_smoke_test.py   # тот же сценарий через реальные HTTP-запросы (нужен запущенный run.py)
```

Оба теста прогоняют пример из handoff §5: 2 собственника в долях (один в браке) +
1 покупатель → ожидаются 6 документов (3 комиссии + основной договор + акт + согласие
супруга). Совпало.

## Как заменить шаблоны на реальные

1. Каждый реальный `.docx`-шаблон должен содержать те же плейсхолдеры, что и тестовый
   (открой любой файл из `templates_docx/` как образец разметки).
2. Положить файл в `templates_docx/`, прописать запись в `templates_docx/registry.json`
   со `status: "active"` — и перевести прежнюю запись того же `document_type`/`deal_type`
   в `"archived"` (на пару может быть только один `active` — правило §5 handoff).
3. Код менять не нужно.

## Что осознанно не сделано (Phase 1 → Phase 2/3, handoff §8)

Несколько сотрудников, роли, БД вместо файлов, мультитенантность, биллинг,
автоматическое подписание без человека в цикле, проверка на 152-ФЗ для внешнего хранения —
не входит в Phase 1.
