# Конструктор договоров Мегаполис

Агент (не веб-приложение) — эксперт-советник по сделкам с недвижимостью + сборщик
комплекта `.docx`-договоров. Работает как диалог в Claude Code, открытый прямо в этой
папке (`CLAUDE.md` — точка входа).

## Статус

Foundation-версия (2026-08-22) — третья итерация архитектуры за два дня:
1. Веб-приложение (Flask + PaddleOCR) — построено, протестировано владельцем вживую,
   найдена структурная путаница интерфейса → заархивировано, не удалено:
   `archive/web_proto/`.
2. Узкая `AGENTS.md`-версия (диалог без веб-форм) — построена, один раз протестирована
   (`deal_c257e114`) → отвергнута владельцем как «узкий скрипт без памяти».
3. **Текущая** — полноценный Foundation-агент (`HOME.md`/`SOUL.md`/`skills/`/`knowledge/`),
   с ролью советника (доли/налоги/нестандартные ситуации) и растущим реестром прецедентов.

Движок сборки документов (`skills/document-assembly/`) не переписывался все три раза —
перенесён как есть, каждый раз проверен сквозным тестом после переноса.

## С чего начать

Открой `HOME.md`. Полная история сборки (все три итерации, найденные баги, независимые
проверки) — `ENGINEER/workspace/2026-08-21-задача-*.md`.

## Структура

```
CLAUDE.md            — точка входа для Claude Code
HOME.md, SOUL.md, ROUTING.md, PROFILE.md, DECISIONS.md, MEMORY.md, OPEN_QUESTIONS.md
knowledge/
  deal-schema.md       — модель данных Deal/Participant, правила комплекта
  precedents.md         — реестр прецедентов (пополняется по подтверждению владельца)
skills/
  document-assembly/    — движок сборки .docx (scripts/ + templates_docx/), Skill
deals/<deal_id>/deal.json   — данные текущих сделок
output/<deal_id>/*.docx     — готовые черновики
examples/                    — образец сделки и стиля диалога
archive/web_proto/           — предыдущая (веб) версия, рабочая, не удалена
```
