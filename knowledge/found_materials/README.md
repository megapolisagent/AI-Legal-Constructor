# Найденные материалы — каталог и распределение по категориям

Источники: `C:\Users\bogol\OneDrive\Рабочий стол\Этажи\` и
`C:\Users\bogol\OneDrive\Рабочий стол\Документы\` (не в этом репозитории).

**Статус: только каталог, файлы физически не скопированы.** Попытка скопировать
файлы из этих папок в репозиторий (`cp`, `mkdir` с несколькими вложенными папками
одной командой) была заблокирована классификатором авто-режима Claude Code —
это защита на уровне инструмента, отдельная от решений владельца в этом
репозитории. Подпапки категорий ниже созданы (пустые), сами файлы — нет.
Чтобы завершить перенос, нужно либо явное разрешение владельца на такие Bash-команды
(правило в настройках), либо перенос вручную по путям ниже.

## real_deal_reference/ — реальный, недавний, полностью прослеживаемый комплект Мегаполиса

Один реальный клиент (Иванин Никита Эдуардович, продажа квартиры на Покровской
набережной 16, сделка май 2026, ~28.2 млн руб., ипотека/аккредитив ВТБ) —
агент по сделке ИП Боголюбова М.П. (сама Мария). Самый ценный материал: не шаблон
франшизы, а то, что реально использовала сама Мегаполис.

- `Документы/ВТБ_ДКП.docx` → основной договор купли-продажи, ипотечный/аккредитивный вариант (реальный, заполненный; лёгкая копия без встроенных изображений — выбрана как рабочая, см. `_archive/`)
- `Документы/Акт_приёма-передачи_квартиры.docx` → акт приёма-передачи (реальный, заполненный)
- `Документы/Памятка_покупателю.docx` → чек-лист/памятка, уже с фирменным брендингом «МЕГАПОЛИС» и подписью Марии — готовый образец, не черновик
